# 部署手册：宝塔 + Nginx + PM2（公网可访问）

> 目标：`http://服务器公网IP/` 打开简历项目，登录、增删改查全部可用。
> 前置：本地 `npm run build` 成功；能连 SSH；有支付宝/微信实名账号。

---

## 0. 现状与架构

```
浏览器 ──80──> Nginx（宝塔站点，托管 dist 静态文件）
                 └── /api/ ──反代──> 127.0.0.1:3001（json-server，PM2 常驻）
```

前端用 `VITE_API_BASE=/api`（已经写进 `.env.production`），所以线上是**同源请求**，不会跨域。

---

## 1. 买服务器（约 10–30 元/月）

- 腾讯云 / 阿里云搜「轻量应用服务器」或「学生机」：**2 核 2G、系统镜像 Ubuntu 22.04、带宽 3M 起**。
- 学生认证：腾讯云「云+校园」、阿里云「高校计划」需学信网/学生证，认证后价格低很多。
- 区域选离你近的（如华北/北京、上海），系统镜像一定选 **Ubuntu 22.04**（别选 CentOS 7，太老）。
- 买完记下：**公网 IP、root 密码**（或密钥）。

> 不建议先绑域名：国内域名要备案（以周计）。先用 IP 访问，面试演示完全够用。

---

## 2. 安全组放行端口

在云控制台 → 防火墙/安全组：
- 放行 **22**（SSH）
- 放行 **80**（网站）
- 临时放行 **8888**（宝塔面板，装完改掉）

> 3001 端口**不要**对外开放，只走本机反代。

---

## 3. 装宝塔面板

用 SSH 登录服务器（Windows 可用 PowerShell 直接 `ssh root@公网IP`），然后：

```bash
# 安装脚本以宝塔官网 https://www.bt.cn 最新版本为准，复制官网给的命令执行
```

装完会输出：**面板地址（http://IP:8888/xxxx）、用户名、密码**——立刻记下来。

装完在宝塔「安全」里：把 8888 改成别的端口（如 42517），并删掉 8888 的放行规则。

---

## 4. 建站点

宝塔 → 网站 → 添加站点：
- 域名：填**公网 IP**（没有域名就填 IP）
- 根目录：`/www/wwwroot/vue-admin`（自动创建）
- PHP 版本：纯静态

---

## 5. 上传前端产物

本地项目里：

```bash
npm run build        # 生成 dist/
```

宝塔 → 文件 → 进入 `/www/wwwroot/vue-admin` → 上传 `dist` 里的**所有文件**（不是 dist 文件夹本身，是里面的 index.html、assets/ 等）。

或者：把 dist 压成 zip → 上传 → 在线解压。

访问 `http://公网IP/`，应该能看到登录页（此时点登录会报网络异常，正常，接口还没起）。

---

## 6. 服务器装 Node + json-server + PM2

宝塔 → 软件商店 → 搜「Node.js 版本管理器」→ 安装 → 选 **v20 或 v22**。

然后 SSH 里执行：

```bash
mkdir -p /www/wwwroot/vue-admin-api
cd /www/wwwroot/vue-admin-api
# 把项目里的 db.json 传上来（宝塔文件管理器上传即可）

npm i -g pm2
pm2 start npx --name student-api -- json-server --watch db.json --port 3001
pm2 save
pm2 startup            # 按提示复制执行输出的那一行命令，开机自启
```

验证本机接口：

```bash
curl http://127.0.0.1:3001/students
```

能返回 JSON 数组就对了。

---

## 7. Nginx 反向代理 /api

宝塔 → 网站 → 你的站点 → 设置 → 配置文件，在 `server { ... }` 里加：

```nginx
location /api/ {
    proxy_pass http://127.0.0.1:3001/;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_http_version 1.1;
}
```

注意 `proxy_pass` 末尾的斜杠：`/api/students` → `http://127.0.0.1:3001/students`，去掉斜杠会变成 `/api/students`（404）。

保存后重载 Nginx（宝塔会自动 reload）。

## 9. 排错对照表

| 现象 | 原因 | 处理 |
|---|---|---|
| 页面白屏 | 上传了 dist 文件夹本身（路径多一层） | 根目录下必须直接是 index.html |
| 登录提示"网络异常" | json-server 没起 / 端口不对 | `pm2 status`、`pm2 logs student-api` |
| `/api/students` 返回 502 | 反代目标没监听 | 确认 `curl 127.0.0.1:3001/students` 通 |
| `/api` 返回 404 | `proxy_pass` 少了末尾斜杠，或 location 写成了 `/api`（少斜杠） | 改成 `location /api/` + 末尾斜杠 |
| 刷新 404 | 用了 history 路由 | 本项目用 hash 路由，正常不会出现；确认访问地址带 `#` |
| 端口 80 打不开 | 安全组/宝塔防火墙没放行 | 两边都放行 80 |
| `npm i -g pm2` 很慢 | 服务器在境外/没有镜像 | `npm config set registry https://registry.npmmirror.com` |
